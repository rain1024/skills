# Skills

A catalog of **skills for Claude and Codex**.

This repository introduces useful skills, explains when to use them, and links to their sources. The catalog grows through practical use, bringing together official, community, and personal skills.

## Goals

- Help users discover useful skills for Claude and Codex.
- Describe each skill's purpose, supported platform, and source.
- Collect installation instructions, usage guidance, and examples where helpful.
- Share practical experience, evaluations, and improvements.

The initial catalog links to each skill's original source. Follow the linked documentation for installation instructions and platform requirements.

## Adding a Skill

Each catalog entry should include:

- **Name and source:** a link to the skill directory or original repository.
- **Platform:** Claude, Codex, or both when compatibility has been verified.
- **Purpose:** what the skill does and when it is useful.
- **Usage:** installation instructions, example prompts, and required tools.
- **Practical notes:** observed results, limitations, or areas for improvement when evaluated.
